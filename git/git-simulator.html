Git 操作シミュレーター

ボタンで操作を選んで実行すると、3つの置き場所（コミット・ステージ・作業ツリー）がどう変わるかが見えて、ここまでに実行した本物のGitコマンドが下に溜まっていきます。複数の操作を順番に重ねて試せます。

詳しい解説は Gitで「混ざった」「戻したい」を自力で直す実践ガイド にあります。

      4. ここまでの実行ログ

      ターミナル

      「コマンドをコピー」は、$ の付いたコマンドだけを順番どおりにコピーします（# で始まる行は「エディタで編集した」などGit以外の操作のメモです）。

      お題：こんなときどうする？

      状況を読み込んでから、自分で操作を組み立ててみてください。詰まったら「答えを見る」。

      このシミュレーターの単純化していること

      • ファイルの中身は「版の数字」で表しています。同じファイルを両側で別々に変更すると、必ず衝突として扱います。本物のGitは行単位でマージするので、別々の行の変更なら衝突しません。
      • .gitignore、リモート（push / pull）、ブランチの新規作成、マージ、rebase は扱いません。
      • コマンドの出力は、Git 2.43 で実際に確認した内容をもとに短くしてあります。
      作業ツリー／ステージ／コミットの動きを、Git 2.43.0 の実際の動作と突き合わせて作っています。
